# 5ch 専用ブラウザ「charis」仕様書

本書は、Rust および Tauri 2.0 で開発された Arch Linux 向け 5ch 専用ブラウザ **charis** の機能仕様、通信プロトコル仕様、操作体系、および内部アーキテクチャを定義する仕様書です。

---

## 1. システム概要

### 1.1 目的・特徴
- **高パフォーマンス・低リソース**: Rust ネイティブバイナリによる高速起動と低メモリ消費。
- **Arch Linux / タイリングWM に最適化**: Vim / Helix ライクな完全キーボードナビゲーション（JKHL、Shift+J/K、Tab、Enter 等）。
- **洗練された 3 ペイン UI**:
  - 左ペイン: お気に入り板 / ブックマーク / 閲覧履歴 / カテゴリ別板一覧（アコーディオン）
  - 右上ペイン: スレッド一覧（勢い順・レス数順・新着順・番号順ソート、インクリメンタル検索）
  - 右下ペイン: スレッド本文（アンカーポップアップ、被アンカーツリー、画像モザイク、同一ID抽出、連鎖あぼーん、自動差分更新）
- **UI 分離アーキテクチャ**: 共通ドメインロジックを `charis-core` クレートに集約し、Tauri デスクトップ版だけでなく将来的な TUI（Ratatui）版への再利用が可能な構造。

## 3. 5ch 通信・プロトコル仕様

| 項目 | 仕様 |
| :--- | :--- |
| **User-Agent** | `Monazilla/1.00 (charis/0.1.0)`（専ブラ形式） |
| **レートリミット** | リクエスト間に最低 1000ms（1秒）のウェイトを `tokio::sync::Mutex` で保証 |
| **文字エンコーディング** | Shift_JIS (CP932 / Windows-31J) を `encoding_rs` で UTF-8 へ確実デコード |
| **板一覧 (BBSMenu)** | `https://menu.5ch.io/bbsmenu.json`（フォールバック: `5ch.net`, HTML版 `bbsmenu.html`） |
| **スレッド一覧 (subject.txt)** | `https://{server}.5ch.io/{board}/subject.txt`<br>行フォーマット: `<key>.dat<><title> (<res_count>)` |
| **スレッド本文 (dat)** | `https://{server}.5ch.io/{board}/dat/{key}.dat`<br>行フォーマット: `名前<>メール<>日付 ID:xxx<>本文<>スレッドタイトル(1行目のみ)` |
| **勢い（ikioi）計算** | $\text{勢い} = \frac{\text{レス数} \times 86400}{\max(\text{現在UnixTime} - \text{作成UnixTime}, 864)}$ |

## 4. UI / 機能仕様

### 4.1 3ペイン構成とフォーカス管理
- アプリケーションは「板一覧（左）」「スレ一覧（右上）」「スレッド本文（右下）」の 3 ペインで構成されます。
- 現在フォーカスがあるペインは外枠に青いフォーカスリング（`outline: 2px solid rgba(55, 148, 255, 0.45)`）が表示され、ヘッダー境界線が強調されます。
- 各ペインの境界（スプリッター）はマウスドラッグで幅・高さを自由にリサイズ可能です。

### 4.2 板一覧（左サイドバー）
- **★ お気に入り板**: 頻繁に巡回する板をワンクリックまたはキーボードで登録・解除。
- **📌 ブックマーク**: スレッド単位で後から読むために保存。
- **🕒 閲覧履歴**: 閲覧したスレッドを自動記録（最新50件上限で自動ローテーション）。「🗑️ 履歴消去」ボタン付き。
- **📁 すべての板**: BBSMenu から取得した全カテゴリ・板のアコーディオンツリー表示。

### 4.3 スレッド一覧（右上ペイン）
- **並び替え（ソート）**:
  - **勢い順**: 現在盛り上がっているスレ順（勢い 300 以上でオレンジ、1000 以上で赤色ハイライト）。
  - **レス数順**: 投稿数が多い順。
  - **新着順**: スレッド作成日時が新しい順。
  - **番号順**: 板のデフォルト並び順。
- **インクリメンタル検索フィルター**:
  - `/` キーで即座にフォーカス。スレタイの部分一致でリアルタイムに絞り込み。
- **お気に入りトグル**:
  - 板タイトルの横にある「★ / ☆」をクリックしてお気に入りを直接切り替え。

### 4.4 スレッド本文（右下ペイン）
- **レスアンカーホバーポップアップ**:
  - `>>1` や `>>1-5` などのアンカーにマウスを乗せると、参照先レスの内容がポップアップ表示。
  - クリックすると該当レスへスムーズスクロール＆ハイライト。
- **被アンカー返信ツリー**:
  - 各レスに対して返信されたアンカー（`💬 返信(3): >>5 >>12 >>20`）を集計してヘッダーに表示。クリックでジャンプ可能。
- **同一ID発言集計 & 抽出モーダル**:
  - ID ごとの書き込み回数をバッジ表示（3回以上で Hot、5回以上で Very Hot）。
  - ID をクリックすると、その ID の発言のみを一覧抽出したモーダルウィンドウを展開。モーダル内からスレッド内の該当レスへジャンプ可能。
- **画像モザイク（Blur）＆クリック解除**:
  - レス内の画像 URL（jpg, jpeg, png, gif, webp）を検知し、インラインサムネイルを表示。
  - 不快画像対策として初期状態でぼかし（モザイク）が適用されており、画像クリックでモザイクの ON/OFF を即座に切り替え可能。
- **外部ブラウザ連携**:
  - 「🔗 元画像」ボタンや本文中の外部 URL（http/https）をクリックすると、OS の `xdg-open` を呼び出してシステムのデフォルトブラウザ（Firefox, Chrome 等）で開く。
- **あぼーん（NG）システム**:
  - レス単位のクイック「🚫 NG」ボタンで即座に NG-ID に登録。
  - **表示方式**: 「あぼーん表示（プレースホルダー [表示する]）」または「透明あぼーん（DOM完全消去）」を切替可能。
  - **連鎖あぼーん**: NG 対象レスへの返信アンカーを含むレスも再帰的に非表示化。
  - **NG 管理モーダル**: NG-ID および NG ワードの追加・個別削除。
- **自動差分更新（実況モード）**:
  - ツールバーから自動更新間隔（5秒, 10秒, 30秒, 1分, オフ）を選択可能。
  - 最下部スクロール時は新着レスに自動追従、それ以外は「新着 +N 件」トースト通知を表示。
- **レス書き込み機能（POST 送信 & 5ch 確認画面対応）**:
  - 各板の `test/bbs.cgi` に対する Shift_JIS (CP932) URLエンコード POST 送信。
  - 5ch サーバーからの「投稿確認」「Cookie確認（上記全てを承諾して書き込む）」画面の自動パース。
  - 確認要求時は確認バナーを表示し、hidden パラメータを引き継いでワンクリック承諾送信。
  - レスごとの「💬 返信」ボタン（`>>{num}\n` の自動補完入力）。
  - 送信完了時のスレッド自動リフレッシュ＆最下部スクロール。
- **環境設定 & カスタマイズ**:
  - UI全体のフォント、フォントサイズ（板一覧・スレ一覧とも連動）。
  - レス本文のフォント、フォントサイズ、行間（リアルタイムプレビュー付き）。
  - スレッド開示時の初期スクロール位置（先頭 / 前回読んだ位置 / 最新レス）。
  - 既読位置（しおり）の自動記録・復元。
  - デフォルトの名前・メール（`sage` 等）設定。

## 5. 操作体系（Vim / Helix ライク キーバインド）

全ペインで共通の移動感覚を保ちつつ、各ペインに最適化された操作を提供します。

### 5.1 全体共通
| キー | 動作 |
| :--- | :--- |
| `Tab` | 次のペインへフォーカス移動（板一覧 ➔ スレ一覧 ➔ スレッド本文 ➔ 板一覧） |
| `Shift + Tab` | 前のペインへフォーカス移動（スレッド本文 ➔ スレ一覧 ➔ 板一覧 ➔ スレッド本文） |
| `/` | スレッド検索ボックスにフォーカス（インクリメンタル検索） |
| `r` | 現在の板 / スレッド / 板一覧の更新 |
| `Escape` | モーダルを閉じる / 検索フォーカス解除 |

### 5.2 板一覧（左サイドバー）
| キー | 動作 |
| :--- | :--- |
| `j` / `↓` | カーソルを 1 つ下に移動（**スレ一覧は読み込まない**） |
| `k` / `↑` | カーソルを 1 つ上に移動 |
| `l` / `→` | カテゴリ・セクションを展開（開く）。板の上で押すとスレ一覧を読み込んでスレ一覧へ移動 |
| `h` / `←` | カテゴリ・セクションを折りたたむ（閉じる）。板の上で押すと親カテゴリに戻って閉じる |
| `Enter` | 板を選択してスレ一覧を読み込み、**フォーカスをスレ一覧ペインへ移動** |

### 5.3 スレ一覧（右上ペイン）
| キー | 動作 |
| :--- | :--- |
| `j` / `↓` | 選択行を 1 つ下に移動（**スレッド本文はまだ読み込まない**）。画面端でスクロール追従 |
| `k` / `↑` | 選択行を 1 つ上に移動 |
| `h` / `←` | フォーカスを**板一覧（左サイドバー）に戻す** |
| `Enter` または `l` / `→` | 選択中のスレッド本文を読み込み、**フォーカスをスレッド本文ペインへ移動** |

### 5.4 スレッド本文（右下ペイン）
| キー | 動作 |
| :--- | :--- |
| `w` | **レス書き込みモーダルを開く** |
| `Ctrl + Enter` (書き込みモーダル内) | **レスを送信する** |
| `r` | スレッド本文を新着更新 |
| `Shift + j` (`J`) | スレッド本文を**半画面下スクロール** |
| `Shift + k` (`K`) | スレッド本文を**半画面上スクロール** |
| `j` / `↓` | スレッド本文をなめらかに下スクロール（設定値 px） |
| `k` / `↑` | スレッド本文をなめらかに上スクロール（設定値 px） |
| `d` (または `Ctrl+d`), `u` (または `Ctrl+u`) | 半画面スクロール（Vim互換） |
| `G` | スレッドの最下部へスクロール |
| `gg` | スレッドの最上部へスクロール |
| `h` / `←` | フォーカスを**スレ一覧ペインに戻す** |

## 6. ストレージ・永続化仕様

XDG Base Directory 規格に準拠し、ユーザー設定・履歴を JSON 形式で保存します。

- **保存ディレクトリ**: `~/.config/charis/` (または `$XDG_CONFIG_HOME/charis/`)
  - `settings.json`: UI/レスフォント・フォントサイズ・行間・スクロール量・初期位置等の環境設定
  - `read_positions.json`: スレッドごとの既読レス番号（しおり・読了位置）
  - `favorites.json`: お気に入り板リスト（`name`, `server`, `board`, `url`）
  - `bookmarks.json`: ブックマークスレッド（スレッド情報 + `bookmarked_at`）
  - `history.json`: 閲覧履歴（最新 50 件を上限として自動保持）
  - `ng_settings.json`: NG 設定（`ng_words`, `ng_ids`, `ng_mode`, `chain_abone`）
